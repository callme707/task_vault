# Lucide icons

The SVG files in this directory are unmodified assets from `lucide-static` **0.468.0**.

- Project: https://github.com/lucide-icons/lucide
- Source: `https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/<name>.svg`
- License: ISC; see [LICENSE](./LICENSE).

The application serves these files locally and does not load icons from a CDN at runtime.
